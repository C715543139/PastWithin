# PastWithin 后续实现计划

本文档记录第一版之后待实现的改进方向。

## 搜索增强

- 仅书签搜索。
- 时间过滤。
- 域名过滤。
- 搜索结果分页。

## 全文查询增强

- 分批扫描,避免一次性阻塞。
- Web Worker。
- 扫描进度事件。
- 停止扫描按钮。
- 先按时间/书签/域名过滤候选集合。
- 短查询确认对话框。

## 采集与正文提取

- 手动保存当前页。
- 支持在设置页自定义单页正文大小上限，替代当前固定 `maxContentLength = 1 MiB`。
- 自定义大小上限需要设置合理边界和提示，例如默认 1 MiB、可选 512 KiB / 1 MiB / 2 MiB / 5 MiB，避免异常页面过度占用 IndexedDB。
- 支持短窗口二次采集：`load` 后先保存一次，延迟 2-5 秒再采集一次；只有正文 hash 或长度明显变化时才覆盖保存，用于覆盖普通异步渲染页面。
- 不默认做长期 `MutationObserver` 兜底，也不追踪滚动加载的内容流页面，避免存储失控、性能开销和隐私风险；这类能力后续仅考虑作为手动保存或高级设置。

## 分词与索引

- 评估是否为分词索引增加重建工具；当前仍处于初期，分词器变更后通过清空本地数据重新采集处理。
- 评估是否将分词查询从 `equals` 扩展为前缀匹配；当前保持精确 token 匹配以降低误召回。
- `contentWords` 截断、去重或单独词表。

## 书签

- 监听 `chrome.bookmarks.onCreated` / `onRemoved` 更新状态。
- 启动时扫描书签并补充记录。

## URL 与存储

- 更精细的 URL 归一化。
- 排除规则改为更友好的域名/通配符规则。
- 数据库增长过快时考虑压缩或更细粒度索引。
- 导入/导出数据库。
