# PastWithin 后续实现计划

本文档记录第一版之后待实现的改进方向。

## 搜索增强

- 仅书签搜索。
- 时间过滤。
- 域名过滤。
- 搜索结果分页。

## 全文查询增强

- 分批扫描,避免一次性阻塞。
- Web Worker。
- 扫描进度事件。
- 停止扫描按钮。
- 先按时间/书签/域名过滤候选集合。
- 短查询确认对话框。

## 采集与正文提取

- 手动保存当前页。
- 更好的正文提取策略。
- 接入 `@mozilla/readability` 作为增强提取器。

## 分词与索引

- 接入 `jieba-wasm` 或其他中文分词库替换/增强轻量分词 fallback。
- `contentWords` 截断、去重或单独词表。

## 书签

- 监听 `chrome.bookmarks.onCreated` / `onRemoved` 更新状态。
- 启动时扫描书签并补充记录。

## URL 与存储

- 更精细的 URL 归一化。
- 排除规则改为更友好的域名/通配符规则。
- 数据库增长过快时考虑压缩或更细粒度索引。
- 导入/导出数据库。

## popup 交互

- 输入防抖 300ms。
- 分词查询实时搜索。

## 其他

- omnibox 地址栏搜索。

## 已知问题

- 同一网址网页的状态会被最新页面覆盖
- 设置页面名 undefined
- 图标
- popup 页面布局优化
- 设置页面布局优化
- 高亮不完全
