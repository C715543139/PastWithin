# PastWithin 后续实现计划

## 搜索增强

- 仅书签搜索。
- 时间过滤。
- 域名过滤。
- 搜索结果分页。

## 全文查询增强

- Web Worker。
- 先按时间/书签/域名过滤候选集合。

## 采集与全文提取

- 支持短窗口二次采集：`load` 后先保存一次，延迟 2-5 秒再采集一次；只有全文 hash 或长度明显变化时才覆盖保存，用于覆盖普通异步渲染页面。
- 不默认做长期 `MutationObserver` 兜底，也不追踪滚动加载的内容流页面，避免存储失控、性能开销和隐私风险；这类能力后续仅考虑作为高级设置。

## URL 与存储

- 更精细的 URL 归一化。
- 数据库增长过快时考虑压缩或更细粒度索引。
- 导入/导出数据库。
