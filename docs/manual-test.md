# 手动安装与验收步骤

## 1. 安装依赖

```bash
npm install
```

## 2. 构建扩展

```bash
npm run build
```

构建产物输出到 `build/chrome-mv3-prod/`。

## 3. 在 Chrome 中加载扩展

1. 打开 `chrome://extensions/`。
2. 开启右上角“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择本仓库下的 `build/chrome-mv3-prod/` 目录。
5. 确认扩展卡片中出现 `PastWithin`。
6. 如果之前安装过旧版本，先在 options 中清空全部本地数据，避免旧分词索引影响本次验收。

## 4. Popup 验收

1. 点击 Chrome 工具栏中的 PastWithin 扩展图标。
2. 确认 popup 正常显示搜索框、搜索方式菜单、搜索按钮和设置按钮。
3. 确认搜索框、搜索方式菜单和搜索按钮在同一行且高度一致。
4. 未搜索时，确认结果区域显示低不透明度应用图标、“在 PastWithin 中搜索过去浏览过的页面”说明，以及分词/全文适用场景提示。
5. 默认保持“分词”，输入关键词后停止输入约 300ms，确认会自动发起分词查询。
6. 连续快速输入多个字符，确认不会每个字符都刷新结果，最后展示完整输入对应的结果。
7. 使用中文输入法输入中文词，确认拼音组合输入过程中不会提前搜索，选词完成后再自动搜索。
8. 切换全文搜索，确认搜索框为空时显示浅色 placeholder：“按 Enter 或点击触发搜索”；输入内容后 placeholder 消失。
9. 在全文搜索下输入连续片段，确认不会实时搜索；按 Enter 或点击“搜索”后才发起全文查询。
10. 在全文搜索下输入 `R2` 或 `tf` 这类长度小于等于 2 的短查询，确认会先提示可能较慢；点击“继续全文搜索”后才发起查询，点击“取消”不会搜索。
11. 关闭“保存全文”后，确认全文搜索不可选择，搜索框为空时显示 placeholder：“保存全文关闭，全文查询不可用”。
12. 首次分词查询可能触发 `jieba-wasm` 初始化；确认首次搜索不会报错，稍后重复搜索响应正常。
13. 确认搜索结果显示圆形浅灰底 favicon 图标；图标获取失败时显示通用地球图标；书签页面在顶部区域右侧用“已收藏”徽标标记，标题和摘要位于其下方，摘要过长时不会超过三行。

## 5. Options 验收

1. 在扩展详情页点击“扩展程序选项”，或从 popup 点击“设置”。
2. 确认可以修改自动保存、仅书签、保存全文、单页全文大小上限、保存天数和最大结果数，且页面不再显示全局“保存设置”按钮。
3. 切换 checkbox 设置后，确认右上角弹出“自动保存于 ...”提示并自动消失，页面布局不被挤动；刷新设置页后配置仍保留。
4. 将单页全文大小上限切换为 512 KiB / 1 MiB / 2 MiB / 5 MiB 中任一选项，确认会自动保存并刷新保留。
5. 修改保存天数或最大搜索结果数为正整数并离焦，确认会自动保存；输入 `0` 或非整数时，确认不会保存并显示错误提示。
6. 确认 URL 排除规则以条目列表展示，每条包含启用 checkbox、规则输入框、保存和删除按钮。
7. 点击“添加规则”后，确认列表底部出现空白规则行；输入非法正则并保存时显示错误，输入合法正则后可保存并刷新保留。
8. 编辑已有规则后，确认该条“保存”按钮可用；保存合法规则后立即生效。
9. 启用/停用已有规则后，确认立即保存；删除已有规则后，确认刷新页面后不再出现。
10. 确认可以查看本地空间占用、页面数量和全文数量。
11. 确认清空全文和清空全部数据会二次确认。

## 6. Content Script 验收

1. 打开一个普通网页，例如 `https://example.com`。
2. 等页面加载完成后打开 popup 搜索网页中的词。
3. 确认被排除 URL 不会保存。
4. 打开包含中文术语的页面后，使用分词查询搜索 `人工智能`、`路径规划`、`知识图谱` 等词，确认能找到页面。
5. 打开包含英文或代码词的页面后，使用分词查询搜索 `pytorch`、`torch`、`total_len` 等词，确认能找到页面。
6. 对连续代码片段或词中间片段，切换到全文查询验证，例如 `Main.gd:328 total_len`。

## 7. Background 验收

1. 在 `chrome://extensions/` 中打开 PastWithin 的 Service Worker 控制台。
2. 确认保存、搜索、设置、统计、清空数据时没有未处理错误。
3. 刷新扩展或等待 Service Worker 休眠后重新搜索中文词，确认 `jieba-wasm` 可重新初始化。

## 8. 书签状态同步验收

1. 打开一个普通网页并等待采集完成，在 popup 搜索结果中确认该页面**未标注"已收藏"**。
2. 在 Chrome 中收藏该页面（`Ctrl+D`），打开 popup 重新搜索，确认该搜索结果**变为"已收藏"**。
3. 在 Chrome 书签管理器中删除该书签，打开 popup 重新搜索，确认该搜索结果**恢复为未收藏**。
4. 搜索一个**从未被 PastWithin 采集过**的书签页面，确认该页面不会凭空出现在搜索结果中（不创建页面记录）。
5. 在 `chrome://extensions/` 中重新加载扩展（或停用再启用），等待数秒后打开 popup 搜索，确认书签状态与当前浏览器书签一致（状态被校准）。
6. 打开扩展的 Service Worker 控制台，确认没有因书签同步导致的未处理错误。
